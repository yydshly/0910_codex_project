## 研究方式

发现与筛选 → 本地体验 → 源码研究 → 实践验证 → 总结归档。

保留原项目链接、所研究的版本及许可证信息。区分原项目能力、实际验证结果与个人推测；优先记录有用的结论和可复现的过程。

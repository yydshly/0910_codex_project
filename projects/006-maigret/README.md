# 006 · Maigret

Maigret 按用户在网站上设置的账号用户名（username / handle，非实名），通过预设站点规则批量检查公开主页或接口，提取公开资料与关联链接。搜索范围限于规则库及本次选择的站点，不覆盖全网；同名账号不等于同一个人。它的主要价值是跨站适配、自动化检查与持续维护。

## 研究摘要

- **核心能力：** 给一个用户设置的账号用户名（非实名），到规则库覆盖的网站检查同名公开账号，再尝试提取资料、递归搜索和输出报告。显示昵称也不一定等于可查询的账号用户名。
- **工作原理：** 站点规则库 → 构造主页或接口请求 → 并发访问 → 按响应特征判断 → 提取与汇总。
- **我们形成的理解：** 大量工作是网站收集、适配和规则维护，也包含请求调度、错误处理、资料提取与报告的工程实现。
- **实际价值：** 节省跨很多网站逐个检查和记录的时间，有机会补充搜索引擎未收录的主页；增量覆盖率未实测。
- **适用场景：** 自有或授权账号盘点、个人数字足迹自查、品牌同名账号候选发现、公开资料研究。
- **能力边界：** 收集的是网站检查规则，不是预先汇总全网用户；存在同名账号不等于确认身份，检测失败不等于没有注册。
- **扩展重点：** 规则质量、证据追溯、人工核验、授权范围内的增量监测和服务化。

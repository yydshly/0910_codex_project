模型服务提供方

02 / THE WORKSPACE

围绕项目，把工具放到手边。

下图来自上游仓库，展示网页对话、项目文件和工具调用记录。右侧为桌面终端窗口，并非网页终端面板。

01编程与工具执行

通过 Pi 读文件、搜索代码、编辑和写入文件、运行命令。提供纯聊天、只读、默认与完整工具预设。

工具预设影响可用工具；不能等同于操作系统沙箱，扩展工具也需单独检查。
02会话与方案分支

按项目恢复、重命名、导出对话；从历史消息新建独立会话，或在原会话内切换分支。

对话分支改变上下文，不会自动回滚项目代码。
03文件与 Git 工作区

浏览和上传文件、检查 Git 差异；预览代码、Markdown、图片、音频、PDF 与 DOCX。通过 worktree 分开不同开发任务。

文件预览能力不等于模型能直接理解所有这些格式。
04模型、插件与 Skills

在网页里登录模型服务、配置 API Key、测试模型，管理插件包和技能。复用 Pi 的配置与会话存储。

模型质量、可用性和费用由所配置的服务决定。
05真实网页终端

xterm.js 展示终端，node-pty 在服务端运行真实 Shell。支持多个终端标签、重连和有限的历史回放。

服务重启后不会悄悄重建此前的终端进程。
06可选子智能体

委派任务、后台运行、查询结果和发送后续指导；可配置角色提示词、模型与工具。

内置功能默认关闭，启用后需要重新加载会话。

04 / WHAT YOU CAN BUILD

把工作台，变成你的研究工具。

这些是基于现有能力的扩展建议，并非上游已经完成的产品功能。

建议方向 / 01

开源项目研究助手

让研究 Skills 统一记录版本、能力、架构与来源，将成果写入编号子项目，并在网页中检查。

建议方向 / 02

开发与审查协作

在已有子智能体之上增加任务依赖、独立 worktree 和验收流程，再接入测试与待审查 PR。

建议方向 / 03

团队共享服务

补充账号权限、隔离的执行环境、凭据管理和审计。现有共享密码登录不等于完整团队权限体系。

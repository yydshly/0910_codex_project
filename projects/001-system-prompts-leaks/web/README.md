# Agent 解剖室 · Web 展示子项目

通过公开仓库材料，解释 Agent 的指令、工具和工作流程。属于研究项目 001，源码独立放在本目录。

## 展示内容

- **能力拆解：** Codex、Claude Code、Cursor、Gemini CLI、Claude Design，共 24 项精选中文解读。每项提供指令要求、任务影响、程序依赖、研究边界与固定版本的原始链接。
- **运行过程：** 修复登录、只做规划、子代理搜索，三个可逐步查看的教学场景。
- **收录全景：** 固定快照的 17 个产品及分类目录，展开后可访问每个文件；共 489 个文件，其中 430 个 Markdown。统计包含说明、历史版本与配套代码，不等于独立提示词或能力数量。
- **意义与用法：** 研究价值、材料与运行能力的边界，以及编码交付、只读调查、团队记忆三个原创迁移示例，分别列出配套工具和评测方法。入口为 `/#meaning`，其他视图支持 `/#explore`、`/#flow` 和 `/#inventory`。
- **案例文档：** [Codex 获取实例与 ChatGPT 5.6 文件详解](../notes/03-codex-acquisition-chatgpt56.md)，网页入口 `/reports/codex-chatgpt56.html`，支持章节导航和下载 Markdown。围绕 PR #166、本地模型缓存和 1,845 行 ChatGPT 样本解释材料来源与范围。
- **完整理解：** [19 个章节的统一整理](../notes/04-complete-understanding.md)，网页入口 `/reports/complete-understanding.html`，整合定位、来源、原理、收录、意义、迁移、扩展与验证边界。六篇研究笔记均有网页阅读版，可互相跳转，并访问研究图。
- **官方 Agent 样例：** [天气助手组成说明](../notes/05-official-agent-anatomy.md)，网页入口 `/reports/official-agent-anatomy.html`，以官方 SDK 文档区分模型、指令、工具、运行循环与按需扩展；附 PNG 和 SVG 组成图。
- **任务逻辑：** 入口 `/#logic`，四条路径共 29 个路径阶段：正常完成（9 阶段 / 4 次模型调用）、检查失败后调整（13 / 6）、修改需要审批（5 / 2）、信息不足先澄清（2 / 1）。每步显示当前依据、模型与程序职责、调用次数、状态和计划；展开可查看输入、输出、执行与反馈示意。附上下文边界、五个常见问题、可放大汇总图与下载。[专题文档](../notes/06-agent-task-loop.md)扩展为 14 节，入口 `/reports/agent-task-loop.html`。

全部交互都在本地浏览器完成，不调用真实模型、不执行上游提示词、不需要 API 密钥。

## 运行

环境：Node.js 18 或更新版本；零第三方依赖，无需安装依赖。

在本目录运行：

```powershell
npm run dev
```

默认访问 http://127.0.0.1:4317/ 。端口可通过环境变量 `PORT` 指定。服务只绑定本机地址，保持终端运行即可继续访问；停止时使用 Ctrl+C。

请通过 HTTP 服务访问。页面使用 ES Modules 并读取目录快照，直接双击 HTML 不属于支持的运行方式。

## 校验与构建

```powershell
npm run check
npm run build
```

校验包括数据与来源路径、场景关联、静态资源、JavaScript 语法及无浏览器的交互渲染检查。

`public/` 是手工维护的源文件；`dist/` 是生成产物，已由根目录规则忽略。构建产物包含相对路径资源，适合部署到独立站点或 Pages 子路径。

例外：`public/reports/` 是由 `../notes/` 内的六篇研究文档生成的阅读副本，并包含来自 `../assets/` 的总览图、Agent 组成图与任务逻辑图副本，单独忽略，不提交。启动和构建时会自动生成；只改文档时可运行 `node scripts/render-report.mjs` 刷新正在运行的本地页面。规范文档、来源索引与图片只在各自原目录维护。

## 文件组织

| 文件 | 职责 |
| :--- | :--- |
| `public/index.html` | 页面骨架、导航和元信息 |
| `public/styles.css` | 桌面与移动端样式 |
| `public/catalog.js` | 24 项精选解读、三个教学场景、三个迁移示例及来源 |
| `public/task-logic.js` | 四条任务路径、调用计数、输入输出示意、上下文边界及汇总图展示 |
| `public/inventory.json` | 固定提交的目录元数据；不包含完整上游文件正文 |
| `public/app.js` | 产品切换、能力面板、步骤浏览与目录展开 |
| `scripts/serve.mjs` | 本地静态服务 |
| `scripts/check.mjs` / `scripts/interaction-check.mjs` | 数据、资源和交互渲染校验 |
| `scripts/build.mjs` | 复制静态源码到构建目录 |
| `scripts/render-report.mjs` | 从六篇研究 Markdown 生成相互关联的网页阅读版、下载副本和内嵌图，并复制结构索引与研究图 |
| `.openai/hosting.json` | 静态托管目录声明；尚无注册站点 ID |

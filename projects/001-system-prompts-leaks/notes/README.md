## 当前理解

在已核对的材料范围内，我们形成了以下认识：

- **Agent 是一个协作运行的系统。** 模型理解和决策，指令组织工作，程序提供上下文、工具执行、权限、状态和交付机制。
- **一次用户任务可以包含多次模型调用。** 程序准备输入，模型提出动作，工具执行后回传结果，模型再判断；也可以直接回答、澄清、暂停或停止。
- **记忆、上下文和状态各有职责。** 记忆用于跨任务复用；上下文是本轮提供给模型的材料；状态记录已发生的动作、结果和等待位置。程序本地依赖不会自动发送给模型。
- **规划与调度需要分清。** 模型可以拆分任务、选择动作并调整计划；程序落实依赖、并行、权限和真实执行，开发者也可以预设部分流程。
- **完成有不同层次。** 形成计划、提出工具请求、执行成功、检查通过和满足用户目标，不能混为一谈；新证据可以改变原计划。
- **Codex、Claude Code 等产品围绕这个基础循环完善工程细节。** 具体版本如何实现，需要结合公开材料、源码和运行证据分别核查。
- **提示词档案提供设计参考。** 上游收集原始材料，我们解释规则、来源和运行依赖；实际收益仍需在自己的任务中实现并验证。现有研究未复现完整产品，也未验证全部收录材料的真实性。

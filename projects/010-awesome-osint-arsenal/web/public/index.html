    04 / 对当前研究的意义

    用它发现候选工具，再选少数深入研究

    与 Maigret 的关系

    Maigret 是其中一条工具记录。它自己负责用户名查询；这个合集让你发现同类和其他方向的工具。

    与研究助手的关系

    可以把目录作为选型资料。若想自动调查，还需要另外接入工具、保存证据并设计核验流程。

    适合下一步做什么

    优先选少量与你有关的工具，补充中文用途、使用条件与验证日期。增加目录条目不等于增加已验证能力。

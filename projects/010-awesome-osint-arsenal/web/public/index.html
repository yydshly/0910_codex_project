    04 / 搜索与更新边界

    查已有清单，不会自动寻找新工具

    网页搜的是什么？

    只搜索固定快照中 753 条记录的名称、用途、分类与标签。中文搜索界面是本研究新增，原库主要提供 README、JSON 和安装脚本。

    工具怎样增加？

    上游作者或贡献者人工收录工具，按需修改安装脚本。我们的网页也需要人工更新快照和重新发布，不自动跟随上游变化。

    以后能自动扩展吗？

    可以另行开发“定期检索 GitHub → 去重与可用性检查 → 人工审核 → 更新目录”。这属于未来设想，当前没有实现。

    05 / 对当前研究的意义

    用它发现候选工具，再选少数深入研究

    与 Maigret 的关系

    Maigret 是其中一条工具记录。它自己负责用户名查询；这个合集让你发现同类和其他方向的工具。

    与研究助手的关系

    可以把目录作为选型资料。若想自动调查，还需要另外接入工具、保存证据并设计核验流程。

    适合下一步做什么

    优先选少量与你有关的工具，补充中文用途、使用条件与验证日期。增加目录条目不等于增加已验证能力。

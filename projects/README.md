# 研究项目

全部研究条目见[首页索引](../README.md#项目索引)。本目录只存放正式研究项目，模板不占用编号。

## 编号与顺序

- 目录格式：`001-project-name`，编号使用至少三位数字补零，名称使用小写英文与连字符。
- 从 `001` 开始递增，新增项目取历史最大编号加一；超过 `999` 时继续使用 `1000`，按数值排序。
- 编号一经分配保持不变，不因更名、暂停或归档而重新编号，也不复用旧编号。
- 首页索引与预览均按编号数值升序排列；一个研究项目占一行。
- 首页项目名链接到对应子项目 README，独立的“原始仓库”列直接链接到上游仓库；在线演示只有在部署并验证后才添加链接。

## 单个项目的结构

```text
projects/001-project-name/
├── README.md          # 项目介绍、结论摘要、图片、运行与演示入口
├── assets/            # 封面、截图与示意图
├── notes/             # 源码阅读、实验记录与专题笔记
└── web/               # 可选：本项目的 Web 演示源码及运行说明
```

复制[子项目模板](../templates/project/README.md)即可开始。额外代码和实验按项目需要添加目录，不统一限定技术栈。默认通过链接引用上游仓库，不将完整上游代码直接复制进总仓库。

## 研究状态

| 状态 | 含义 |
| :--- | :--- |
| 待研究 | 已收录，尚未开展验证 |
| 研究中 | 正在体验、阅读源码或实验 |
| 已总结 | 已完成当前范围的研究与结论整理 |
| 已归档 | 暂停维护，保留已有资料 |

演示是否上线与研究状态独立：未部署时填写 `—`，不使用尚未生效的预计地址。

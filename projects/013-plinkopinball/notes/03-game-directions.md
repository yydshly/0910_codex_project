# 八种游戏方向：第二版挑战玩法

本研究在 013 子项目中制作八个独立的二维游戏原型，比较弹珠交互可以发展出的产品方向。本版重点把单一规则演示升级为需要操作、规划和取舍的短局挑战。它们不是上游已有游戏，不复制上游 Three.js、Rapier 游戏代码、模型、纹理或音频。

## 1. 如何体验

选择方向后默认自动演示；切换“亲自试玩”会重新开始。每种玩法都有练习、挑战、大师三档，难度切换会重开当前局。自动模式使用同一套碰撞、计分和胜负规则；演示操作可读取完整游戏状态，因此不代表人类玩家的水平。

暂停、重来、全屏、结果回顾和方向 hash 继续保留。新增局内进度、关键资源提示、三星评级与本机最佳成绩。成绩按玩法和难度分开，优先比较星级，相同星级再比较用时；只记录手动、非辅助通关。自动演示、中途接管演示和轨道提示练习不会计入纪录。本机存储不可用时仍能玩，但不能保存成绩。

## 2. 八种玩法与操作

| 方向 | 本版新增玩法 | 操作与取舍 | 实现方法 |
| :--- | :--- | :--- | :--- |
| 三星引力实验 | 三星收集、两块可调斜板、初速度、有限投球、上一球轨迹 | 先规划再发射，飞行时锁定机关；挑战档初始配置需要调整，收齐三星且入杯才成功 | 重力积分、圆与线段接触、轨迹记录与距离判定 |
| 钥匙迷宫 | 三把钥匙、锁定出口、检查点、有限救援、倒计时与刹车 | 方向键 / WASD / 触点倾斜，空格刹车；速度越快越需要预留制动距离 | 可变重力、阻尼、接触求解、区域检测与检查点恢复 |
| 反应堆砖块 | 护甲耐久、爆破砖、空中连锁、限时宽板和穿透、两次冲击波 | 指针或左右键移动挡板，空格发出冲击波；在砖块密集处释放更有效 | 碰撞法线、耐久状态、递归区域伤害与到期时间 |
| 有限轨道 | 三块锁定轨道、旋转预算、撤销、单步提示 | 点击旋转，先规划再试跑；用完预算可撤销。提示和示例路线标为辅助 | 四向端口、路径遍历、最少旋转预算与操作历史 |
| 脉冲机关 | 三个独立延迟、可调球速、有限开门窗口与到达时间图 | 开得过早或过晚都会失败；整颗球必须在关门前通过。图中金线表示球心预计到达时刻，需留出球身余量 | 事件触发、时间窗口、区间碰撞和一维运动 |
| 三波分拣 | 24 球、三波加速、箱位换序、连击奖励与三次容错 | 按 1 / 2 / 3 选实际路线；每波清空后箱子才换位，跟随 A / B / C 标记而不是死记颜色位置 | 波次状态机、路口锁定、类别映射与奖励计算 |
| 双轨演奏 | 27 音符，切分、三次双押、三次长按、精准判定与空击惩罚 | F / J 或左右按钮；长尾要按住。空击扣 25 分并断连，得分率至少 70% 才通过 | 时间轴、按下 / 释放事件、长按状态与判定窗口 |
| 三圈大奖赛 | 三圈比赛、危险弯道、打滑惩罚、刹车、每圈补能与动态对手速度 | 空格加速，Shift 刹车；直道超车、弯道控速，每圈补能 25。挑战档全程加速会因多次打滑而落后 | 曲线弧长、路段规则、速度插值、失控积累与冲线时间 |

节奏声音为浏览器即时合成的节拍，默认关闭，需用户主动开启。长按按钮支持触摸与键盘，节奏双押需要同时操作两个按键或两个触点。竞速切换路线会重新开局。

## 3. 三档难度与评级

难度改变实际规则，不只是标签：物理解谜改变投球预算、星星判定范围和初始配置；迷宫减少救援与可用时间；砖块增加护甲并减少生命；轨道缩减多余步数；机关缩短开门窗口；分拣提高速度；节奏提升 BPM 并收紧窗口；竞速增加对手速度和超速失控累积。

| 方向 | 三星条件 | 二星条件 | 一星条件 |
| :--- | :--- | :--- | :--- |
| 物理解谜 | 第一球成功 | 三球内成功 | 在预算内成功 |
| 迷宫 | 45 秒内，且未使用救援 | 70 秒内成功 | 在时限内成功 |
| 打砖块 | 未损失生命 | 剩余至少两次生命 | 成功清空 |
| 轨道 | 达到当前拼图的最少旋转数 | 预算内独立完成 | 使用提示或示例完成 |
| 机关 | 通过三道脉冲门 | 本场景不另设 | 本场景不另设 |
| 分拣 | 24 球全对 | 23 球正确 | 22 球正确 |
| 节奏 | 得分率至少 95% | 得分率至少 85% | 得分率至少 70% |
| 竞速 | 第一名且未打滑 | 第一名且打滑最多两次 | 第一名完成 |

三档是相同场景的不同规则参数，不等于 24 张独立地图。自动解法、固定谱面和固定订单可复现，便于比较机制；重复游玩的关卡丰富度仍有限。

## 4. 验证范围

2026-09-10 本版通过 Node 独立逻辑检查：八种玩法 × 三档难度，共 24 条自动通关路径，全部经过真实规则获得成功。模拟用时约为：物理解谜 3.3 秒、迷宫 12 秒、轨道 8.8 秒、机关 4.7 秒、分类 29–36 秒、节奏 13–16 秒、竞速 24.6 秒、打砖块 24–51 秒。这些是模拟时间，不是设备性能测量或人类通关时间。

额外检查包括：

- 未调整的挑战档物理解谜无法直接成功，发射锁定、三星条件、轨迹保留与投球次数上限生效。
- 迷宫钥匙解锁、检查点救援、救援耗尽、刹车和超时分别生效。
- 护甲砖耐久、道具拾取和有效期、冲击波次数限制、最终漏接失败。
- 锁定轨道、旋转预算、撤销、提示计步、运行中禁止修改及辅助评级。
- 机关过早关闭与过晚开启都会失败，合适的独立延迟可通过。
- 分类换位只在清空上一波之后发生，路线锁定、三次错误和连击计分有效。
- 空击扣分、双押、长按完成和提前释放失败，终局后不再重复计分。
- 两条竞速路线都能合理操作获胜；不加速会落后；挑战档一直加速会打滑并失败；三圈、补能和能量边界有效。

绘制函数在代表状态和两组尺寸参数下通过有限数值检查；这只检查绘图调用契约，不验证实际视觉效果。构建继续检查页面链接、脚本语法、静态 UI 引用和 Markdown 下载一致性。可选 WebMCP 仍只提供启动指定方向及自动 / 手动模式，输入契约通过模拟接口检查。

本版提供本地预览，并按仓库流程验证上线文件。未执行浏览器截图、真实点击、移动设备、真实音频延迟、视觉回归或真实 WebMCP 浏览器测试。

## 5. 与完整产品的差距及下一步

- **三维表现：** 当前仍为原创二维几何场景。若达到上游的精细三维效果，需要独立模型、材质、灯光和设备性能优化。
- **物理能力：** 物理解谜、迷宫和打砖块使用简化接触求解；轨道、机关与竞速使用受约束的路径运动，没有自由三维刚体仿真。
- **内容与留存：** 本版增加了局内目标、资源限制、评级与本机纪录，尚无完整关卡包、成长系统、跨设备存档或线上排名。
- **节奏专业化：** 谱面为原创规则生成；尚未做音频时钟驱动、延迟校准或真实音乐授权接入。
- **产品探索：** 轨道与机关可继续发展为关卡创作和自动化解谜；砖块可加入武器组合与 Boss；分拣可发展多人协作；竞速可加入幽灵回放和赛季。上述方向尚未验证商业需求。

上游整体许可证仍需单独核实。本原型的独立实现，不代替未来复用上游资产时的许可确认。

# Pi 能力实验室

一个独立的静态 Web 展示，帮助理解 Pi 如何把模型、工具、上下文和会话组织成 Agent。展示源码位于本项目 `web/`，不另分配研究编号。

## 展示内容

| 交互 | 可以体验什么 |
| :--- | :--- |
| 完整理解 | 在线阅读八节中文总稿：本质、能力、任务流程、方法与扩展、使用价值、边界和验证状态；正文从同一份 Markdown 生成 |
| 理论双图 | 完整架构与技术能力、业务调度泳道流程；支持标签切换、键盘切换、缩放、适应宽度与 SVG/PNG 下载，附 18 组来源 |
| 执行实验室 | 修复代码、研究开源项目、调用知识检索扩展，共三条路径、18 个步骤；支持自动播放、暂停、单步、任意阶段跳转、重置与重放 |
| 能力地图 | 八项能力的作用、原理、场景、边界与固定版本来源 |
| 会话分支 | 从共同上下文选择两种方案，查看当前对话路径 |
| 上下文压缩 | 切换压缩前后示意，理解摘要、近期消息和原始历史的关系 |
| 扩展工坊 | 组合 Prompt Template、Skill、Extension、Pi Package，比较 16 种组合 |
| 来源与研究 | 回到上游固定提交，下载完整中文分析 |

所有模型答复、工具结果、文件变化和上下文数值都是预设教学示例。本页不调用 API，不读写用户文件，不安装扩展，也不运行上游 Pi。`knowledge_search` 是假设的业务扩展，不是内置工具。压缩数值不构成实测收益。

## 本地运行

需要 Node.js；本次验证环境为 Node.js 22.15.0。没有第三方依赖，也无需安装步骤。

在 `projects/004-pi/web/` 目录执行：

```powershell
node scripts/build.mjs
node scripts/check.mjs
node scripts/serve.mjs
```

预览地址：[http://127.0.0.1:4324/](http://127.0.0.1:4324/)。只有本地服务运行期间可访问；端口占用时可通过 `PORT` 指定其他端口。

完整理解总稿使用 `/understanding.html`；理论图谱：[http://127.0.0.1:4324/theory.html](http://127.0.0.1:4324/theory.html)，业务流程可通过 `#flow` 直接进入。双图已导出为独立图片，离线阅读见 [理论分析](../notes/02-architecture-and-scheduling.md)。

构建把 `public/` 与研究笔记复制到本项目 `dist/`；预览读取构建结果，修改后需重新构建。构建只清理经过路径检查的本项目输出目录，生成内容不提交。

## 检查范围

- JavaScript 语法、动态目标元素、页面锚点、相对资源、研究下载文件。
- 理论页来源索引、18 组证据、图谱文件、标签关联与缩放控件目标；PNG 已目视检查，未进行浏览器视觉或真实点击测试。
- 三条任务结束与重放、切换任务、跳转、暂停及重置的状态逻辑。
- 全部 16 种扩展组合，以及包分发不等于业务能力的边界。
- 压缩示意中近期内容保留、示意切换与 HTML 转义。
- 页面提供键盘焦点、移动布局和减少动态效果设置。未执行浏览器截图、视觉或真实点击测试。

播放中切换任务会停止原播放；切到后台会暂停。交互选择只存在当前页面内，刷新后重置，不保存个人信息。

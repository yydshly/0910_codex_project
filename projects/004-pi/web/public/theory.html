READ THE SYSTEM

读图时，把这几层分开。

下载完整理论分析 ↓
01

人定义目标，模型选择动作

模型根据上下文生成工具名称与参数。Pi 负责校验、执行、保存与回传。测试或业务验收负责判断结果是否正确。

02

AgentSession 包住 Agent 循环

Agent 循环推进模型与工具。AgentSession 在外层处理输入、资源、压缩、重试和收尾，因此一次 agent_end 之后仍可能恢复并继续。

03

两种输入队列有不同时间点

steer 在工具批次之后、下一次模型响应之前送入；followUp 在内循环准备结束时读取。它们不会强行抢占正在执行的工具。

04

常用接入与实验服务分开读

CLI RPC 用 JSONL。实验性的 client / protocol / server 使用路由信封与 CBOR 分帧，Session/Harness 留在拥有它们的进程中。

05

历史保存、上下文与记忆不同

会话文件保留历史；模型只看到本轮整理后的上下文。压缩是有损摘要，切换会话分支也不会自动回滚工作区文件。

06

工作流和安全边界需要定制

Skill 提供方法，扩展提供工具和钩子。业务审批、任务调度、系统隔离与授权，需要由具体应用及执行环境负责。

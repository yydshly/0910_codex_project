# 中文学习网页：内容与验证

日期：2026-09-10。上游版本：fdd5dbbb02ebf3ed316f66db2af62dbad4e39455。

本文记录初版学习网页。后续增加的关键知识清单见 [查漏说明](05-key-knowledge.md)。

## 交付与目标

20 个静态页面：学习地图、18 个学习单元、来源与范围页。帮助建立理解、查原书、回答自检、保存疑问，再带着上下文回到助手对话学习。

引导语要求助手一次解释一个概念，给例子并提问，等回答后纠正和推进。网页本身不运行 AI 导师。

## 覆盖口径

- 固定版本 17 份 RST 文件共 204 个标题；顶级标题对应单元，187 个下级标题逐项提供原创中文导读和原文行号。
- 书稿工程为额外第 18 单元。
- 57 个术语入口含缩写与同义词，不等于 57 个独立算法；47 条书目记录提供固定行号。
- 18 道开放自检题与参考思路；完成标记属于自评，不进行自动能力认证。
- 未搬运整本书稿。中文解释、例子与问题是研究补充，出处和原文状态独立展示。

## 新发现的缺口

PBKDF2、bcrypt、scrypt 只有标题，Password strength 为 TODO；TLS 的自签名证书小节仅标题，现代握手待补；OTR 的 Data exchange 为 TODO。签名、椭圆曲线与侧信道也有空白或引用入口。已修正之前笼统的“有内容”表述。无 TODO 标记不证明技术内容完整或正确。

## 体验边界

笔记与进度在当前浏览器 localStorage，不跨设备同步，清理浏览器数据会删除记录。存储失败时提示，静态阅读继续；复制受限时选中引导语供手动复制。按钮只复制，不发送消息。

独立 HTML 页面可直接访问，资源使用相对路径。禁用 JavaScript 仍能阅读和展开原生自检详情；保存和演算不可用。

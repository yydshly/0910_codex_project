日期：2026-09-10。版本：`fdd5dbbb02ebf3ed316f66db2af62dbad4e39455`。依据书稿静态阅读，章节链接见[来源表](02-sources-and-verification.md)。

## 1. 交付物是什么

它交付一本书的可编辑源文件、插图组织和构建流程。读者消费知识，贡献者维护书稿。它不提供业务可调用的统一加密 API、密钥托管服务或自动漏洞扫描功能。

序言的目标是帮助程序员建立对完整密码系统的整体认识。它不是读完即可成为密码学专家的承诺，也不把自行拼装协议当作学习终点。

## 2. 基础组件覆盖什么

| 主题 | 已看到的内容 | 可以形成的理解 | 完整性与使用边界 |
| --- | --- | --- | --- |
| XOR | 位运算与异或基础章节 | 为密钥流与后续构造建立直觉 | 单个基础运算不构成完整方案 |
| 分组密码 | AES/Rijndael 步骤、DES/3DES 背景 | 算法处理固定大小的数据块 | 历史性能比较不等于今天的测试 |
| 流密码与模式 | ECB、CBC、CTR、密钥流、位翻转攻击 | 工作模式、重复与篡改如何影响安全 | 可加解密不代表具备完整性保护 |
| 密钥交换 | Diffie–Hellman、离散对数、椭圆曲线相关解释 | 建立共享秘密与验证身份是不同任务 | 章节有待补充项，不是部署手册 |
| 公钥加密 | RSA 数学、实现陷阱、OAEP | 数学原语与完整方案的差别 | 椭圆曲线加密小节仍有 TODO |
| 哈希 | MD5、SHA 家族、密码存储、盐、长度扩展、哈希树 | 摘要、密码存储与认证用途不同 | 历史算法描述不作为当前选型依据 |
| MAC 与认证加密 | prefix-MAC、HMAC、一次性 MAC、AEAD、OCB/GCM | 加密或裸哈希为何不能单独解决认证 | 个别攻击讲解待补充 |
| 数字签名 | DSA 参数、签名/验证、随机参数问题 | 公钥验签与共享密钥认证的区别 | RSA 签名的 PKCS#1 v1.5、PSS 及 ECDSA 有 TODO |
| 密钥派生 | HKDF；PBKDF2、bcrypt、scrypt 仅标题 | 密码派生与已有秘密扩展是不同任务 | 不是当前参数推荐清单，未实测性能 |
| 随机数 | 真随机来源、CSPRNG、Dual_EC_DRBG、Mersenne Twister | 看似随机与密码学用途合适需要区别 | Yarrow、Blum Blum Shub 等部分待完成 |

这里按书中实际组织整理，分组工作模式出现在 `stream-ciphers.rst`，避免仅凭文件名漏掉重要教学案例。

## 3. 漏洞案例怎样帮助理解

书中先提出看似可用的构造，再解释问题，借此引入下一种组件。以下是教学主题，不是本次运行结果。

| 案例 | 要理解的失败原因 | 后续阅读 |
| --- | --- | --- |
| ECB 重复结构泄漏 | 相同输入块对应相同输出块，可暴露结构 | 分组模式与信息泄漏 |
| CBC/流密码位翻转 | 密文可被修改，解密成功不表示消息未被篡改 | MAC、认证加密 |
| prefix-MAC 长度扩展 | 不恰当地将部分哈希构造用作认证机制 | HMAC 与消息格式 |
| 弱密码存储 | 密码分布与快速猜测使“存一个哈希”不足以解决问题 | 盐与密码派生 |
| 签名随机参数问题 | 随机参数的错误使用会破坏签名安全 | DSA、随机数 |
| 随机数生成器案例 | 可预测状态或特殊结构影响密钥安全 | CSPRNG、Dual_EC_DRBG 背景 |

本次没有运行攻击程序、恢复密码或访问目标系统。书中的代码片段未经本项目运行和安全审计。

## 4. 怎样进入完整系统

- **SSL/TLS**：讨论证书、CA、客户端证书、前向保密、降级和 CRIME/BREACH 等背景。握手小节保留“解释现代 TLS 握手”的 TODO，不能宣称完整覆盖 TLS 1.3。
- **OpenPGP/GPG**：介绍相关概念和信任网。该章篇幅较短，适合理解信任关系，不宜宣传为全面运维手册。
- **OTR**：作为消息系统案例连接加密、认证与可否认性等概念。本次未复现协议交互。

三类系统共同说明：加密、认证、密钥建立和信任关系各负其责，选一个算法不能替代完整系统设计。

## 5. 仓库工程能力

```text
src/index.rst                   全书入口
├─ building-blocks.rst          基础目录 → 各主题 .rst
├─ complete-cryptosystems.rst   系统目录 → TLS / GPG / OTR
├─ appendices.rst              数学附录
├─ glossary.rst                术语表
└─ zreferences.rst             参考资料入口

src/Illustrations/             插图
src/conf.py 与 Python 扩展      排版、语言、引用、自定义指令
Makefile / make-lang           构建目标与语言参数
docker/                       构建依赖环境
             ↓
HTML / LaTeX PDF / EPUB        源码声明的目标，未本地验证
```

`make book` 将 HTML、LaTeX PDF、EPUB 作为目标；`make-lang` 接受语言代码并设置输出目录/配置。它具备多格式与翻译工作的基础设施，但不保证当前所有格式可成功生成，也不证明指定语言已有完整译文。

## 6. 对当前项目集的意义

**知识整理**：建立术语表、按问题写中文笔记、比较安全组件职责。**文档工程参考**：从需求和失败案例引出下一主题，集中维护图文、引用与构建。**后续演示方向**：解释重复数据块或加密/认证的不同目标；这些是扩展设想，现已提供中文学习网页和小型 XOR、密钥交换演算，未复现攻击或真实协议。

若需求是直接给业务接入加密，实际实现仍需选择其他库并独立验证。

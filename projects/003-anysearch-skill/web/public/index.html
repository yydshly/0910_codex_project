客户端开源 / 搜索由云端执行

一个搜索服务，
供 Agent 使用的入口。

AnySearch Skill 是 AnySearch 云端检索服务的开源客户端与使用规范。它把搜索能力交给已有 Agent 调用，实际搜索在 api.anysearch.com 完成。

理解需求，选择工具和参数，读取结果后组织回答。

这个开源仓库

AnySearch 云端

02

特殊能力，来自更具体的查询。

通用搜索返回相关网页；专业查询可以使用股票代码、DOI、航班号或软件版本等参数，取得相应领域记录。统一接口可能减少逐个接入数据源的工作。

通用搜索

问题或关键词 → 标题、链接与摘要。单次返回 1–10 条。

专业查询

标识与筛选条件 → 行情、论文引用、航班、漏洞等记录。

并行检索

最多 5 个查询同时执行，允许部分失败；每项分别计入请求额度。

正文抽取

URL → 可读正文。支持网页、文本、JSON、Markdown；不支持 PDF、Word、图片和音视频。

专业能力 ≠ 第三方会员

能查论文、金融或新闻，不代表拥有知网、付费研报、金融终端或新闻付费墙的访问权。

03

比较服务本身，也比较实现边界。

同类方案不只以 Skill 形式出现。API、MCP 或内置工具都能成为 Agent 的入口；决定价值的是信息来源、覆盖、质量和成本。

方案主要能力对我们的参考价值
TavilyAgent 搜索、筛选、抓取与提取对照检索上下文与工具接口
Exa自有索引、语义检索、内容获取理解自建索引型服务的差异
Brave Search API独立网页索引与排序比较上游搜索来源与覆盖
Parallel搜索、提取、多步骤研究理解检索与研究流程的结合
Perplexity Search排序结果、过滤与内容获取区分返回资料与生成答案
SerpApi提供 Google 等搜索引擎结果研究搜索结果 API 的接入方式
Firecrawl搜索、抓取与正文提取研究开源实现；云端与开源能力有边界
SearXNG聚合多个上游搜索来源服务端开源，可自行部署与研究

相邻组件 Crawl4AI 适合研究浏览器采集和正文清洗，本身不等于完整全网搜索索引。以上为定位比较，未进行统一质量排名。

05

对我们有用的，是哪一部分？

学习客户端

有清楚的参考价值

能力目录、参数设计、并行请求、错误处理、多语言适配，以及如何让 Agent 正确使用工具。

研究搜索后端

需要看其他项目

索引、路由、排序与抓取实现没有公开。可进一步研究 SearXNG、Crawl4AI、Firecrawl 的相应开源部分。

判断是否安装

看实际增量

缺少搜索工具时，它能提供入口；已有搜索时，应验证它是否带来缺失数据、更好结果或更低成本。

研究判断：适合参考服务接入设计；无法仅靠这个仓库研究或部署完整搜索后端。专业目录的丰富程度，仍需通过实际任务检验。

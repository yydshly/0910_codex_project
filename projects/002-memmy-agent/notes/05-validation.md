# 研究页面排错与验证记录

日期：2026-09-10。对象是本项目原创研究文档和静态页面，不是上游 Memmy 或 Mnemosyne。

## 修复与完善

| 发现 | 处理 |
| --- | --- |
| 手机选择架构层后，说明在图后不易发现 | 窄屏自动定位说明标题，提供返回所选节点按钮，支持键盘焦点 |
| 外部执行层也指向 Memmy 自带 Runtime 代码 | 按模式区分执行详情和来源，外部模式指向适配文档 |
| 刷新后丢失模式与层选择 | 用 URL 参数保存有效选择，刷新恢复；非法值回退默认 |
| 手机对照表需要横向滚动 | 窄屏改为按维度逐项堆叠，明确两个项目标签 |
| 构建只复制文件，可能残留废弃文件 | 校验本项目输出目录后清理生成产物，拒绝重定向目录 |
| 检查可能使用过时产物 | check 先构建，再检查静态内容与 HTTP 行为 |
| 请求处理缺少异常细分 | 补充错误路径、HEAD、方法限制与模块 MIME 验证 |
| 内容只到总体架构 | 补充六阶段流转、ID 与接口职责、失败回退、模型数据流和评测建议 |

文章中的 AI，分别能做什么？

以下五个案例帮助理解文章涉及的领域，供有相关需求时查阅。它们的能力属于各自项目，不能当作汇总网页的功能，也不代表当前安排了进一步研究。

电脑操作 · 评测环境论文摘要与代码入口已核查

Windows Agent Arena

给 AI 一台 Windows 电脑和一组任务，测量它完成任务的表现。

具体能力
提供可复现的 Windows 任务环境，评估屏幕理解、操作规划和工具使用。
使用场景
研究如何测试桌面助手；设计“完成文件整理”等可判定结果的任务。
研究价值
有电脑智能体评测需求时，可参考任务定义、执行记录和成功判定。
使用条件
需要 Windows 实验环境、模型接入与运行资源；本次没有部署或实测。

Factorio Learning Environment 原文列于 Paperplane

让 AI 在工厂游戏中建生产线，观察它能否规划、执行和处理失败。

具体能力
在持续变化的游戏状态中，评估长期规划、程序生成与资源优化。
使用场景
比较不同智能体如何拆解长任务、应对资源不足和修复执行错误。
研究价值
适合借鉴“用可观察结果评估复杂任务”的设计。
使用条件
需要游戏运行环境和模型配置；游戏成绩不直接等于真实业务能力。

Latent Program Network 原文列于 Ndea

从几组输入和输出中，寻找能解释这些例子的程序表示。

具体能力
学习程序的连续表示，并在遇到新问题时通过搜索改进候选解。
使用场景
研究少样本规则推断，以及如何让模型在回答前花更多计算寻找解法。
研究价值
适合算法研究；能帮助理解生成一次答案和持续搜索的区别。
使用条件
论文在特定基准上评估；不能由此推断它能自动开发任意应用。代码版本与复现条件待核查。

JETS Empirical Health

从可穿戴设备记录中，学习与健康状态有关的数据规律。

具体能力
学习稀疏、不规则的行为时间序列表示，用于健康相关预测研究。
使用场景
研究传感器数据表征、缺失数据处理和预测任务。
研究价值
有相关数据和专业背景时值得深入；普通网页开发的直接复用价值较少。
使用条件
需要核查数据获取、隐私条件、模型与临床验证范围；本文不提供健康诊断。

Concept Bottleneck 蛋白质模型 Guide Labs

通过可解释的结构概念，引导模型生成具有目标特征的蛋白质。

具体能力
把人可以理解的蛋白质概念作为控制生成过程的中间层。
使用场景
研究如何让专业人员控制生成结果，并观察控制与结果的关系。
研究价值
专业生物科研价值较高；一般 AI 产品可借鉴“可解释控制”的思路。
使用条件
